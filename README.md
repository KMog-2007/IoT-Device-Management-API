# IoT Device Management REST API

A Python-based REST API for managing IoT devices and sensor readings using FastAPI, SQLite, SQLAlchemy, and Pydantic.

## 📌 Project Overview

The IoT Device Management REST API is a backend application designed to manage IoT devices and the data generated by their sensors.

The API provides functionality to:

- Add IoT devices
- View all registered devices
- View individual devices
- Update device information
- Delete devices
- Add sensor readings
- Retrieve sensor readings for a specific device
- Retrieve individual sensor readings
- Protect API endpoints using token-based authentication
- Test APIs using interactive Swagger documentation

This project demonstrates how Python can be used to build a backend system for an IoT application.

## 🚀 Features

### Device Management

The API supports complete CRUD operations for IoT devices.

- Create a device
- Read device information
- Update device information
- Delete a device

Each device contains:

- Device ID
- Device Name
- Device Type
- Location
- Status

### Sensor Reading Management

Sensor readings can be associated with a specific IoT device.

Each sensor reading contains:

- Reading ID
- Device ID
- Sensor Type
- Sensor Value
- Unit
- Timestamp

Example sensor reading:

    {
      "sensor_type": "temperature",
      "value": 28.5,
      "unit": "°C"
    }

### 🔐 API Authentication

The API uses HTTP Bearer Token Authentication to protect device and sensor-related endpoints.

For this learning project, the token is:

    iot-secret-123

The token can be entered using the Authorize button in Swagger UI.

Note: The token is hard-coded only for learning and demonstration purposes. A production application should use environment variables and a secure authentication system such as JWT.

## 🔗 API Endpoints

### General Endpoints

    GET /

Checks whether the API is running.

    GET /about

Returns basic project information.

### Device Endpoints

    POST /devices

Creates a new IoT device.

    GET /devices

Returns all registered IoT devices.

    GET /devices/{device_id}

Returns a specific device using its ID.

    PUT /devices/{device_id}

Updates an existing device.

    DELETE /devices/{device_id}

Deletes an existing device.

### Sensor Reading Endpoints

    POST /devices/{device_id}/readings

Adds a sensor reading to a specific device.

    GET /devices/{device_id}/readings

Returns all sensor readings associated with a device.

    GET /readings/{reading_id}

Returns a specific sensor reading.

## 🗄️ Database Design

The application uses SQLite for data storage.

SQLAlchemy is used as the Object Relational Mapper (ORM) to interact with the database using Python classes.

### Devices Table

The devices table stores information about registered IoT devices.

    devices
    |
    ├── id
    ├── name
    ├── device_type
    ├── location
    └── status

### Sensor Readings Table

The sensor_readings table stores measurements generated by IoT sensors.

    sensor_readings
    |
    ├── id
    ├── device_id
    ├── sensor_type
    ├── value
    ├── unit
    └── timestamp

The device_id connects each sensor reading to its corresponding device.

## ▶️ Running the Application

Start the FastAPI development server using:

    python -m uvicorn main:app --reload

The API will run at:

    http://127.0.0.1:8000
